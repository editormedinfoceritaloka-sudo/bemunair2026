# Shared Admin Components

- Shell: shadcn Sidebar, Sheet, Breadcrumb, Avatar, DropdownMenu, Separator and Tooltip.
- Data: reusable DataTable/Table, StatusBadge, MetricCard, EmptyState, ErrorState, Skeleton and Pagination.
- Forms: Field, Label, Input, Textarea, Select, Command/Combobox, Popover, Dialog, AlertDialog and Sonner.
- Article: NotionEditor, EditorBubbleMenu, SlashCommandMenu, SaveIndicator, CoverPreview and ArticlePreview.
- Accessibility: semantic headings/tables, labelled controls, visible focus, keyboard menus/dialogs, aria-live save/toast states, WCAG AA contrast.
